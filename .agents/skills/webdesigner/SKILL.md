# Web Designer Pro Skill — Studio & DAW Design System

This skill provides professional guidelines for building high-end creative web applications, audio workstations (DAWs), and developer tools, avoiding cheap saturated neon gradients and clichés.

## 1. Professional Dark Palette (No "AI Neon")

- **Obsidian / Slate Base**: Use deep carbon foundations (`#080a0d`, `#0e1117`, `#141822`, `#1b202c`) with crisp 1px borders (`rgba(255, 255, 255, 0.08)` to `0.14`).
- **Precision Hardware LED Accents**:
  - Gold / Amber (`#f59e0b`, `#fbbf24`) — Warm studio hardware tubes, indicators, highlights.
  - Phosphor Emerald (`#10b981`, `#34d399`) — Signal present, playback active, verified state.
  - Studio Cobalt (`#3b82f6`, `#60a5fa`) — Focus indicators, primary routing, selection rings.
  - Coral / Crimson (`#f43f5e`, `#fb7185`) — Record arms, solo/mute warnings, clipping peaks.
- **Surface Elevation Hierarchy**:
  - `Surface-0` (`#080a0d`): Canvas background / viewport floor.
  - `Surface-1` (`#0e1218`): Panels, toolbars, racks.
  - `Surface-2` (`#151922`): Channel cards, module containers.
  - `Surface-3` (`#1e2430`): Recessed wells, input fields, active button states.

## 2. Hardware Console Ergonomics

- **Tactile Sliders & Faders**: Recessed track lanes with high-contrast indicator thumbs and subtle thumb shadows.
- **Knobs & Meters**: Crisp segmented or gradient level meters with peak holds and decibel scales.
- **Dense, Legible Typography**: Clean sans-serif UI typography with monospace numbers for BPM, timestamps, frequency, and gain readouts (`tabular-nums font-mono`).

## 3. High-End Micro-Animations

- Smooth animated border beams on active states (`BorderBeam`).
- State-aware thinking orbs (`ThinkingOrb`) communicating audio engine and neural processing status.
- Spring-damped panel resizes and tab transitions.
